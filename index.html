Что такое вайбкодинг?

Вайбкодинг — это подход к разработке, где код рождается в состоянии потока. Вместо механического написания строк вы входите в ритм задачи, чувствуете архитектуру и позволяете решениям приходить естественно.

В мире 1С это особенно мощно. Когда вы глубоко понимаете бизнес-процессы и владеете платформой, код становится продолжением мысли. AI-инструменты усиливают этот поток, превращая идею в работающее решение за минуты, а не дни.

«Лучший код пишется не руками — он пишется состоянием. Вайбкодинг — это когда ты и машина думаете вместе.»

Я совмещаю многолетний опыт в 1С с современными AI-подходами, создавая инструменты и решения, которые ускоряют разработку в разы. Этот сайт — точка входа в мой мир вайбкодинга.

PromptPilot

Background task queue для AI CLI

Универсальный планировщик промптов для Claude Code, Codex, Qwen, Cursor и любых других AI CLI. Очередь с приоритетами, расписание, автоматический retry при rate-limit, Web UI и Telegram-бот с авторизацией по номеру телефона.

Python 3.10+ FastAPI SQLite Telegram Bot PyInstaller
  • Мульти-провайдер: Claude / Codex / Qwen / Cursor / OpenCode — или свой кастомный CLI
  • Exponential backoff при rate-limit (60s → 1h) + crash recovery воркера
  • Telegram-бот: создание задач, выбор модели, скилы Claude Code, продолжение сессий
  • Повторяющиеся задачи (daily@09:00, 6h) и фоновый detached-запуск
  • Standalone pp.exe + tray-приложение для Windows

Claude Note

Автосинтез знаний из сессий Claude Code → Obsidian

Фоновый сервис, который слушает хуки Claude Code и через ту же модель синтезирует ключевые решения, паттерны и открытые вопросы из транскриптов сессий в ваш Obsidian-vault. Дополнительно ведёт MEMORY.md в каждом проекте — Claude перестаёт забывать контекст между сессиями.

Python 3.11+ Claude Hooks Obsidian Windows · macOS · Linux qmd · semantic search
  • Hook-интеграция: PostToolUse, UserPromptSubmit, Stop → очередь событий
  • Synthesis-режимы: log / inbox / route — маршрутизация по существующим заметкам vault
  • Auto-Memory: децки MEMORY.md с дедупликацией и pruning по бюджету строк
  • Архив всех промптов в отдельной заметке + tracker открытых вопросов
  • Web UI на :8080 и трей-приложение cn.exe для Windows

Записная книжка / Zapis

Локальная транскрибация и LLM-постобработка

Десктопное приложение для офлайн-транскрибации аудио и видео с таймкодами на уровне слов. Два движка распознавания на выбор — GigaAM v3 (русский) и faster-whisper (мультиязык). LLM-постобработка превращает транскрипт в YouTube-описание, таймкоды, Telegram-пост или статью.

Python FastAPI pywebview GigaAM v3 + KenLM faster-whisper OpenAI · Anthropic
  • Таймкоды на уровне слов с точностью до 40 мс
  • Экспорт TXT / SRT / VTT — готовые субтитры для YouTube и плееров
  • 4 пресета LLM-обработки + свободные вопросы к транскрипту
  • SSE-стриминг ответов LLM с fallback-цепочкой по профилям
  • Standalone Zapis.exe, модели подтягиваются лениво из HuggingFace

OneBase

Открытая 1С-подобная платформа на Go

Одна папка с YAML-метаданными + один Go-бинарник на 20 МБ + PostgreSQL — и через 10 минут у вас работающая учётная система с веб-интерфейсом, проводкой документов, печатными формами, отчётами с диаграммами и REST API. Совместима по подходам с 1С: справочники, документы, регистры, запросы на русском, .os-модули — но открытая, кроссплатформенная и без лицензий.

Go 1.23+ PostgreSQL 14+ WebView2 DSL: 1С-подобный язык ECharts Cloudflare Tunnel
  • Лаунчер «Запуск 1С:Предприятие» — управление списком информационных баз
  • Два режима конфигурации: файловый (git + hot reload) или в БД (визуальный конфигуратор)
  • DSL: Запрос, Движения, НачатьТранзакцию, Попытка, ТабличныйДокумент
  • Диаграммы в отчётах — программно, как в 1С (гистограмма / линейная / круговая)
  • Работает на Orange Pi 4GB: 5–10 баз и сайт проекта одновременно
Доступ к демо: логин Пользователь · пароль 12345

77MCP / mcp-1c77

MCP-сервер для анализа метаданных 1С 7.7

Подключает Claude Code и других MCP-клиентов к старым конфигурациям 1С:Предприятие 7.7. Парсит OLE-контейнер 1Cv7.MD и скобочный синтаксис, открывает LLM доступ к справочникам, документам, регистрам, формам и исходному коду модулей — включая глобальный модуль и пакетные запросы.

Python 3.11+ FastMCP MCP over SSE OLE Compound Doc Docker
  • 15+ MCP-инструментов: list_objects, get_module, search_in_modules, resolve_id
  • Валидация путей реквизитов и текста запросов: Товар.Артикул → ✓ / ✗
  • Извлечение исходного кода глобального модуля с авто-усечением для больших файлов
  • Полнотекстовый поиск по всем модулям с контекстными строками
  • Web-интерфейс для drag-and-drop файла 1Cv7.MD + Docker compose

ConfluenceMCP

Умный поиск по корпоративной wiki через MCP

MCP-сервер, который даёт Claude доступ к Confluence — локальному или Atlassian Cloud. Запрос «как оформить звонок в директорат» находит статью со словом «принять» благодаря трём независимым механизмам умного поиска: score-merging, выделение существительных и опциональная LLM-переформулировка через любой OpenAI-совместимый endpoint.

Python 3.10+ MCP · SSE + Streamable-HTTP pymorphy3 Confluence REST Basic Auth · API Token Docker
  • Score-based ranking: страница, найдённая 5 вариантами запроса, ранжируется выше
  • Noun-only проход через pymorphy3 — убирает глагольный шум из запроса
  • LLM-rewrite: генерация синонимичных формулировок с тихим fallback при ошибке
  • 6 инструментов: search_content, search_by_cql, get_page_content, list_spaces…
  • Работает с локальным Confluence и Atlassian Cloud, поднимается одним docker compose up
